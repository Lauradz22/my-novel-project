# My Novel Project

A responsive webpage created as part of my web development learning journey. This project allowed me to practise building and styling a webpage from scratch using HTML and CSS.

## About the project

The goal of this project was to create a visually structured webpage while developing my understanding of HTML structure and CSS styling.

## Technologies used

- HTML5
- CSS3

## What I learned

Through this project, I practised:

- Structuring a webpage with semantic HTML
- Styling and organising content with CSS
- Working with images and visual elements
- Organising project files and folders

## Project structure

- `index.html` — main webpage
- `css/` — stylesheets
- `images/` — project images
